# ExerCube SDK
SDK for developing ExerCube applications using Unity3D.

## Requirements
### System
* [ExerCube](https://sphery.ch/exercube/)
* Computer (only Windows 10 support for now)
  * [Unity3D - 2019.4.11f1](https://unity3d.com/get-unity/download)
  * [Steam](https://store.steampowered.com/about/)
  * [Steam VR Runtime](https://store.steampowered.com/app/250820/SteamVR/)

### Unity Project
* [SteamVR Unity Plugin - v2.7.2 (sdk 1.14.15)](https://assetstore.unity.com/packages/tools/integration/steamvr-plugin-32647) (included)
* Required packages
  * Koboldgames Primitives Package (included)
  * Koboldgames Non-Null Package (included)
  * Cinemachine 2.3.4
  * TextMeshPro 2.1.3
  * Universal RP 7.3.1 (Builtin Renderer only works in certain hardware configurations)
  * UnityUI 1.0.0
  * OpenVR XR Plugin 1.1.4

## Installation
* Ensure your **system meets the requirements** mentioned above.
* Download the latest SDK package.
* Create a new Unity project or just copy the whole project within the SDK package as a starter project.
  * For newly created projects copy at least the contents from the **Assets** and **Packages** folder and ensure your project meets
    the **Unity project requirements** mentioned above.
